# Temu 深采助手

## 0.5.5 回传失败与继续

图片下载使用 25 秒总时限（含响应体），按流检查实际字节，不信任 content-length，超过 25MB 停止。图片站下载、图片域名授权和本机接收分别记录失败阶段/代码；提示只显示站点主机名，不显示图片签名参数或远端 HTML。HTTP 拒绝/登录页面不会绕过，其他图片仍可继续。

本机断线、超时、配对失效或服务 5xx 后停止本轮，区分成功、失败与未处理；部分失败保持“等待授权回传图片”，不再误报全部完成。先处理提示，再点发送复用原任务并跳过本机已保存图片。图片下载失败与本机接收失败不能混为同一种 Failed to fetch。权限范围不变，不导出 Cookie；本地回归不等于 Temu 实网通过。

升级到本版客户端并启动后，在原扩展目录重新加载，不卸载、不清存储。弹窗标题和扩展管理页均应显示 0.5.5；重新配对后继续原清单。

## 0.5.4 操作入口

“1. 采集当前商品 → 2. 发送到本地工作台 → 3. 查看下载任务”移到弹窗首屏，采集参数与自动深采默认折叠。提示依据清单和本地任务 ID 更新；已有任务不代表图片全部完成，应进入客户端核对。发送期间禁止重复发送和同时采集，保留图片域名即时授权；轮询不再覆盖正在编辑的任务名。权限范围不变，不读取或导出 Cookie。

客户端接收后：更多 → 统一任务中心 → 对应采集任务 → 查看/继续。结果页显示下一步和本地图片预览；下载 ZIP、解压后，可进入 SKU 图包处理。更新扩展请重载原目录，不卸载或清除存储；旧客户端不会自动升级，真实图片回传仍需实际确认。

## 0.5.3 回传请求恢复（继承）

首次创建任务需要 Windows 客户端 0.12.0 或具备同等请求幂等能力的源码后端。扩展先保存本轮请求标识、商品和规则，再发送；服务器已建任务但响应丢失时，重新发送会找回原任务。浏览器后台重启后仍沿用原请求，不因修改界面规则而创建替代任务。已知任务 ID 的继续回传不受这个首次创建版本检查影响。

未确认任务 ID 时，不允许“重新准备”“采集当前页”或“重试失败商品”覆盖原回传；可重新配对后继续发送。确需新轮次时，先查看任务中心，再明确确认重置；重置不会删除服务器已有任务。工作空间恢复旧备份导致请求记录缺失时，会停止并提示检查，不默默另建任务。此保证针对本扩展的带标识创建请求，不涵盖旧扩展、普通 Web 表单或手动清除扩展数据。

## 0.5.2 连接与回传诊断

首次发送前必须在“客户端连接”填写 Windows 客户端显示的动态端口地址并配对，安装扩展不等于完成配对。不会再静默回退 4000；只有源码开发模式显式启用才连接无鉴权开发服务。“检测连接”仅确认服务可达与身份，实际回传仍校验权限。

看到 Failed to fetch 时不要清空清单或重复采集。先核对客户端窗口中的地址和服务状态、浏览器本地网络权限，再生成新配对码并连接。直接在 Edge 打开客户端地址会因没有本地会话而被拒绝；地址应填写在扩展里。更新扩展后需在 edge://extensions/ 重新加载，保持相同扩展目录，手动清单仍保存在原扩展本地存储中，再重新配对。

图片域名授权由“发送”按钮点击即时触发，不导出 Cookie。未连接时不创建新任务，失败保留手动清单；配对过期、服务超时、端口错误等提供明确建议。新客户端让配对错误响应可读，不把鉴权失败伪装成无说明网络错误。

## v0.5.0 Windows 客户端连接

1. 在客户端打开“更多 → 客户端与恢复”，生成一次性配对码。
2. 在扩展展开“客户端连接”，填写客户端显示的 `http://127.0.0.1:端口` 和配对码。
3. 配对成功后即可回传采集数据；“打开下载任务”通过客户端协议激活桌面任务页。
4. 配对码 5 分钟有效、仅用一次。扩展会话保存在浏览器会话存储；客户端或浏览器重启后重新配对。

客户端自动分配端口，不需要另行启动 4000/5173 服务。下方固定端口说明仅适用于旧的源码开发模式。

这是本地工作台配套的 Chrome/Edge Manifest V3 扩展。它使用用户自己已经登录的 Temu 浏览器会话，提取标题、页面可见销量和图片地址，并创建本地可恢复采集任务。v0.4.0 提供低风控手动采集和保守自动采集两种方式；不会伪装浏览器指纹，也不会绕过验证码。

v0.4.0 会合并页面可见图、懒加载属性、`srcset`、背景图、JSON-LD/页面 JSON 和脚本中的图片地址，并保留变种图片及来源统计。手动完成采集时可选择由当前登录会话下载图片二进制并回传到 `127.0.0.1`；扩展不会读取或导出 Cookie，图片域名权限由浏览器显式询问。

## 0.5.1 恢复与回传

深采完成后显示“等待授权回传图片”，点击“发送到本地工作台”再授权图片域名。重复发送复用原任务并跳过已存图片；所有图片齐全时本机自动完成清单和 ZIP。回传中断后可重新配对再发送。

“只重试失败商品”创建仅含失败 URL 的新轮次，不重新访问成功商品，原任务保留。暂停在商品间也会立即持久化。更新后请在扩展管理页重新加载；本地状态机测试不能代替 Temu 实站验证。

## 安装

1. 保持后端运行在 `http://127.0.0.1:4000`，前端运行在 `http://127.0.0.1:5173`。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择本目录：`browser-extension/temu-deep-collector`。

## 使用

推荐使用手动采集：

1. 正常登录并手动打开一个商品详情页，等待图片加载完成。
2. 点击扩展里的“采集当前商品”。继续正常浏览其他商品并重复操作。
3. 保持“用当前登录会话下载图片”勾选，采集完后点击“生成下载任务”。浏览器会按实际图片域名请求权限；拒绝后仍会保留链接任务。
4. 打开本地任务。已经由浏览器回传成功的图片会断点复用，其余地址仍可由本地下载器继续尝试。

保守自动采集：

1. 打开商品列表或搜索结果页，适当向下滚动，让商品卡片加载出来。
2. 点击“识别当前列表”，再点击“开始/继续”。
3. 默认复用一个专用标签页，每个页面等待 6 秒、商品间隔 8 秒；每处理 3 个商品强制冷却 60 秒。
4. 出现验证码或安全验证时，扩展保存进度并暂停。人工完成验证后再点击继续。
5. 完成后点击“打开下载任务”，由本地工作台执行图片下载、断点续跑和 ZIP 导出。

Temu 的风控由平台决定，保守参数只能降低访问压力，不能保证不触发验证。扩展不会绕过登录、验证码、访问控制或平台限制；页面结构变更时，未识别字段会保留为空并记录失败。
