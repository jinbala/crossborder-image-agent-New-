# Windows 客户端

双击 `release/Crossborder-Workbench-Portable-0.23.0.exe` 使用便携版，或安装 `release/Crossborder-Workbench-Setup-0.23.0.exe`。以验收记录中的最终构建为准。旧版制品保留；如果正在采集，先结束或暂停当前任务，再从托盘退出旧版并启动新版。0.17.x 页面内尚未导出的人工验收报告需先导出；新版不能找回旧版从未持久化的页面内存。

完整证据及仍待验收事项见 [0.23.0 验收记录](../docs/verification-0.23.0.md)。本版迁移导出/上传预检/沙箱报告和扫描/队列受控标签，补齐严格配置显示与真实样本预览参数。此前源图解码预检、多目标隔离、来源过滤、JPEG/数量/散列一致性、队列保护与恢复入口继续包含；扩展仍为 0.5.3，不会替用户重启旧客户端。

后端 613/613、前端 262/262、桌面单元 17/17；最终源码窗口与成品独立验证正在进行，不提前计为通过。制品散列和最终状态见验收记录。完整双语仍需开发；用户已确认扩展配对“已连接”，图片实站回传、模型许可/质量与干净机等条件继续保留，未验收项不因打包自动关闭。

运行数据保存在 `%APPDATA%/CrossborderWorkbench/workspace`，安装目录与运行数据分开。卸载保留运行数据和输出。

关闭窗口后客户端留在托盘；右键托盘可打开工作台、暂停队列或退出。退出只停止本客户端创建的本地服务。

“更多 → 客户端与恢复”提供目录导入、未完成任务、数据目录、日志、诊断包、服务重启和扩展配对。

恢复清单每页 50 条，旧清单后台分批索引并自动刷新，完成后停止轮询；连续读取失败三次后请手动刷新。异常退出后重新打开会进入恢复页，核对断点后再继续；正常退出仍进工作台，明确的商品深链接优先。旧客户端未写过运行标记时无法回溯判断其退出情况。损坏清单计数但不改原文件，管理员可从任务中心确认重建索引。独立 Web 的“技术支持”只读角色不能访问业务数据。角色变化、停用或改密码撤销旧会话、设备及待用配对码，恢复角色不会自动复活旧令牌。

“浏览器扩展”打开的是用户数据目录中的稳定可加载目录，而非 app.asar 内部或便携版临时解压目录。Edge/Chrome 首次加载此目录；扩展更新到 0.5.3 后在扩展管理页重新加载，不要卸载或清除存储。深采后点击“发送到本地工作台”回传图片，也可单独重试失败商品；未确认首次创建的请求时，先继续原发送或明确重置。

## 开发与验证

```powershell
npm.cmd install
node node_modules/electron/install.js
npm.cmd run native
npm.cmd start
npm.cmd run smoke
npm.cmd run dist
node scripts/validate-package.mjs
```

`native` 将 SQLite 依赖编译/下载到 Electron 对应 ABI，不修改 backend 自己的依赖。

构建只复制源码、构建后页面、扩展和指定文档，不复制 `.env`、数据库、账号、图片、日志或浏览器资料。

`smoke` 使用独立的 `.smoke-data`，会自动检查实际窗口、本地 API、SQLite、图片压缩、ZIP、单实例、服务重启和数据保留。打包 EXE 同样支持 `--smoke-test --smoke-root=绝对测试目录`。

“更多 → 设备绑定与同步”：在独立 Web 工作空间生成 5 分钟配对码，在客户端绑定 HTTPS 工作空间地址。只同步任务摘要，凭据经 Windows 安全存储加密；离线队列与冲突保留在本机。

“客户端与恢复 → 配置本地 rembg”：选择已安装的 `rembg.exe` 和模型根目录。依赖、权重与模型许可必须分别就绪；未确认许可不会自动下载或执行模型。

## 更新发布配置

自动更新框架已实现，但当前未配置发布者公钥和 HTTPS 更新源，因此保持关闭。安装包尚无 Windows 代码签名证书，不能宣称通过 SmartScreen 或干净机验收。

发布者在打包前创建 `src/update-trust.json`（已忽略提交），只允许 `feedUrl` 与 PEM 格式 `publicKey`。必须使用 Ed25519 公钥，严禁放入私钥。使用 `node scripts/sign-update.mjs --help` 查看签名工具；工具不自动发布。签名清单绑定版本、发布日期、说明、同源 HTTPS 下载地址、大小及 SHA-256。

更新页面先检查、展示说明，再由用户批准下载，校验通过后另行批准安装。安装新版本前必须通过原生对话框导入当前版本的签名清单与安装包，作为回退包。当前包、目标包都会在安装前重新验证。更新失败不删除业务数据；回退应用不自动降级数据库，请先备份。

`--smoke-test` 额外运行独立 Web 服务：初始化账号、登录/退出、页面访问、真实 Windows 凭据加密、设备同步与撤销。测试账号和数据仅存在于指定测试目录，不接触用户工作空间。
