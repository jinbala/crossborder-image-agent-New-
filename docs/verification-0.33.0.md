## 实现范围

- image-pack、collection-plan、studio、listing-dry-run、pricing-preview、template-fill 六类任务，在有效备份/已发布 ZIP 的只读结果页增加“预览并修复主清单”。采集执行和 SKU 沿用各自独立恢复协议；本地模拟商店不走此文件协议。
- 仅管理员/运营且具有任务访问权可修复。预检绑定任务、当前成员、工作空间恢复纪元、损坏主清单及恢复来源散列；来源变化拒绝覆盖。保留原损坏内容，按来源原始字节原子替换主清单，不修改备份、图片、ZIP 或业务状态；没有主清单时不伪造损坏副本。
- 修复和普通清单写入共用任务锁，模板执行持有同一把锁直至副本与报告保存，避免两者并发覆盖。操作期间阻止工作空间恢复。仅模板内部的清单保存可受控重入，修复不能借重入再启动写入。现存锁（包括中断锁）不自动删除；请保留并人工检查，不能把“锁存在”猜作可安全回收。
- 模板恢复快照不能直接执行，服务端拒绝、界面禁用。先明确修复，仍保持 waiting_user；之后须再次确认逐格差异才生成副本。修复不会自动执行任何任务或调用外部 Provider。其他普通任务的任意中途续跑器不在本轮冒充实现。
- 沿用已翻译的恢复提示、修复按钮和确认文案，不翻译文件名、SKU、下载 JSON 或原始错误。不清空扩展清单、不重启用户客户端。
