# 0.22.0 多目标导出与源图预检验收

日期：2026-10-21。Windows 0.22.0 / 扩展 0.5.3。对应需求第 4.3 节状态/数量、6.4 图片格式、7.1 输出包和 8.1 异常隔离，以及图片处理到刊登资料的本地衔接。原需求基线不变，不把导出通过等同于官方平台上传成功。

## 实现范围

- 前后端共享纯目标解析规则：优先 targetId，其次有唯一匹配的 platform/site/language；未知、冲突或多个候选不借用其他目标图片。旧任务没有 targets 时采用确定性的默认目标，不每次生成随机身份。
- 同平台多个目标分别有目标子目录、清单、CSV 行与 target_id/site/language 字段；单目标保留旧目录/列契约。目标目录有身份后缀，连同原有 Windows 大小写冲突检查防止覆盖。单任务界面按目标显示最新有效版本，不把同平台图片重复算给两个站点。
- 单任务目标 ZIP 同时隔离图片、图片计划、提示词和对应审核；未知目标直接拒绝。导出前校验源图实际路径、完整解码、文件名和归档内重名，失败不留下伪成功 ZIP。每次导出生成唯一文件名，以 wx 模式创建，保留旧导出和散列，输出有 SHA256/字节数。
- 结构化包预览对所选源图进行完整解码，不只检查任务字段；缺失/损坏等错误提前进入目录树，给出 checkedAt/sourceFilesChecked/noSourceWrite。生成时再次验证，仍逐图失败继续，最终数量、清单、界面和包内 CSV 以实际写入为准。预检不是对未来文件的锁定或原子快照。
- 来源过滤统一：fallbackMock/mock 的证据优先于矛盾的 real 标记；includeMockImages=false 排除两者，真实样本需独立严格布尔开关。被排除的图片不读磁盘，不回退借用较旧版本。未知来源显示未验证，不把元数据判断称为真实性鉴别。独立 CSV 是资料草稿，不进行磁盘预检；包内 CSV 才绑定本次实际输出路径。
- 队列增加只读、非持久化的 runtime.queueActive，覆盖日志/统计收尾阶段。界面此时继续轮询、禁用操作并显示收尾提示；暂停的已结束 worker 不永久轮询。启动/暂停/恢复/取消/失败重试响应和单条/列表读取一致，原有在途锁、取消、超时排空门禁保留。
- 新增源图预检、目标警告及收尾提示 3 条双语文案，词典 2,242 项。不是完整双语交付。

结构化包保留 reviewScope=task，表示 SKU 审核风险来自任务级报告，不将其伪装成每个站点独立官方审核。安全说明继续区分“不修改任务业务数据”和“创建输出访问授权记录会写数据库”。
