# 0.34.0 普通图包逐图检查点与明确恢复

日期：2026-10-24。对应 WEB-TASK-001、DESK-RECOVERY-001 和需求第 4.3/7.2/8.1 节。本轮不宣称全部需求完成。

## 范围与边界

- 新建普通图包先将全部上传输入持久化到任务私有 inputs，再逐图写入检查点；调用者临时上传目录删除后仍可继续。单张坏图记录失败并继续，清单汇总成功/失败/待处理的真实数量，ZIP 只包含成功图片和清单，不包含输入缓存。
- 结果页分别确认继续待处理、重试失败、仅重新打包。已完成图片只校验散列，不重做；失败重试生成新版本 ZIP，旧 ZIP 保留。暂停/取消在当前图片结束后落盘，取消不能降级为暂停；打包保存阶段不接受虚假的停止回执。
- 预检绑定成员、工作空间纪元、清单和输入/输出散列；重新核对后才运行。明确权限、成员隔离、CSRF、任务互斥和工作空间恢复屏障。只用本地 Sharp，不上传图片、不调用外部抠图服务。
- 中断锁仅在 PID 可以证明确已退出、且用户批准当前锁散列的范围后，改名留存副本并恢复。存活 PID、无法判断及格式未知的锁均拒绝回收；PID 重用宁可拒绝，不猜测死亡。清单只读恢复须先独立修复，不自动续跑。旧版本没有输入缓存的图包明确要求重新导入。
- 中文及带空格前缀纳入恢复与 ZIP 验证。普通图包之外的非图片计划/预演不伪称具备通用中断执行器。
