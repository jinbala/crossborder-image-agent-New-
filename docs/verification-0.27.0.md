## 实现范围

- templateAudit、singleImageGeneration（三样本比较在内）、reviewReport、autoFixPlan、finalAcceptance 的受控标签和格式化消息显式接入当前翻译函数；所有 useMemo 同时依赖报告和翻译函数，切换语言不重载任务、不重挂载表单。
- 新 reportDisplayLabels 只映射白名单内的状态、图片类型、风险、动作、模块等稳定代码；未知代码及原型键保留原文，不把任意商品、模板、Provider/model 名、报告警告或用户备注传入翻译函数。请求与表单的实际枚举值不变，JSON/CSV 下载使用原报告。
- 修正模板覆盖摘要把任意已齐全覆盖一律写为“8 类”的问题，改为真实 expectedImageTypes 数量。缺失或非布尔的安全检查不能显示通过，字符串 false/true 不当作已生成或已通过；有明确风险则显示未通过，缺少明确结果显示未检查。
- 三样本页面费用勾选只接受布尔 true，不再把字符串 false 或任意对象当作批准；后端原严格门禁保持。模板 JSON 导出确认使用当前语言，取消不创建下载。
- 新增文案 110 条，词典 2,476 条。后台尚无稳定代码的系统建议、既有临时反馈的即时语言刷新和 Electron 原生弹窗等完整双语继续开发，不能由静态 JSX 审计或本批报告替代。
- 窗口回归发现 Windows EPERM：图片处理和断点已完成，旧 ZIP 仍在，新 ZIP 临时文件已产生，但发布未完成。新增 atomicRename 只对 EPERM/EACCES/EBUSY 做最多 8 次有界退避，总等待 4,500ms，不先删除旧文件，不重做图片或 Provider 请求。其他错误直接返回，永久失败保留旧包与准备文件。
- 打包或发布失败保存 finalizePending 恢复点，提供“仅重新生成结果包”；旧 ZIP-lock 断点也可通过服务端实际临时文件/状态预检进入。仅最终化为 0 SKU/0 输入图、remote=false，必须当前 hash/人工确认，不要求已完成图片的输入缓存或远程费用批准。
- 最终化预检散列绑定已有输出树中的相对路径/字节散列，拒绝 junction/软链接与目录越界；执行锁内复核，临时 ZIP 生成后、发布前再校验输出，变化则保留旧发布包并暂停。恢复 ZIP 写入新的审批清单，成功图片的内容与修改时间不变；失败 SKU 重新处理仍是独立的明确选项。
- Windows 真实读句柄测试复现了无法替换已打开 ZIP 的问题；恢复现在发布带版本号的独立 ZIP，不覆盖之前的包。发布前持久化最终化恢复点，只在新文件成功发布后更新下载地址；发布回执丢失也不会重做图片。主清单损坏时读取最新已发布版本，最新包损坏则明确拒绝，不静默退回更旧的包。客户端明确区分上次保存的包与恢复包，接口失败后重新读取恢复点并保留原始错误。
