# 0.20.0 历史任务恢复与容量验收

日期：2026-10-21。Windows 0.20.0 / 扩展 0.5.3。范围：DESK-RECOVERY-001、需求 8.1 异常退出恢复及 8.2 导入/分页性能。需求基线和 68 项范围不变。

## 本轮实现

- 恢复页在历史索引 pending/running 时自动刷新，完成或失败后停止。连续读取失败最多重试三次，之后显式刷新；不无限请求。刷新错误单独显示，不覆盖其他操作结果。换页、换成员或离开页面取消旧请求，迟到响应不能覆盖新页面。
- 客户端在用户配置目录单独保存运行标记。上次未正常退出或标记损坏，下次默认进入恢复页并提示人工确认；不自动续跑、调用收费服务或写入平台。正常退出不改变原入口；已校验的显式商品深链接优先。最近一次标记保留为 .previous，不放入业务备份，不包含凭据。
- 独立 Electron 子进程/测试配置目录放置 10,000 份真实历史 manifest，以上次 running 标记模拟异常退出后重新启动。测试检查实际恢复页面、自动索引刷新、30 秒内出现 50 条、完成后总数、两页无重复、停止轮询、渲染器心跳、零自动业务写入、正常退出标记，以及全部源清单 SHA256 不变。
- 另通过真实本地 HTTP 表格导入接口分别创建 1,000 行 CSV/XLSX 待执行任务，验证行数、状态和 10 秒目标；不运行任务、不访问其中的 benchmark.invalid 地址。

这是进程冷启动和本机元数据负载测试：没有清空操作系统磁盘缓存，没有模拟真实图片下载、模型推理、多人并发或干净 Windows。隐藏测试窗口关闭后台计时节流以近似前台渲染心跳；不能据此宣称所有 ZIP/模型负载均无卡顿。异常退出前的 running 标记为夹具，不冒充真实采集任务中途断电。
