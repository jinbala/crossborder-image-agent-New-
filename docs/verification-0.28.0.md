## 本轮实现

- SKU 结果页、完整清单下载、恢复预检统一使用 skuPackStateService，只读打开有效主清单、较新的备份或最新已发布 ZIP。主清单缺失/JSON 损坏可回退；身份不符、权限、路径异常不能当作普通损坏绕过。最新 ZIP 损坏不静默退回旧版本或重做已完成图片。
- 主清单/备份/ZIP 必须在当前授权任务实际目录内；拒绝目录别名、junction/链接、非普通文件、过大清单、重复或加密 ZIP 清单、CRC 错误和外部/可执行下载地址。使用当前已安装 adm-zip 的异步限长解压与 CRC 检查，不执行包内文件。不宣称已做独立安全审计。
- 结果页明确显示备份/ZIP 只读来源，完整清单走受成员权限保护、no-store 的 API，下载实际完整快照而非损坏文件或分页数据。进入、刷新、语言切换与下载不修复原清单、不启动图片处理。
- “预览并修复主清单”先读预检，再人工确认。审批绑定成员、工作空间世代、当前主清单与来源散列；执行锁内重新读取并核对。修复仅原子发布已有有效清单，保留损坏原文件副本，记录修复准备/完成审计，不改图片/ZIP、不调用 Provider。来源变化拒绝旧确认；回执丢失后相同有效内容不重复写入。
- 修复与继续 SKU/仅打包恢复是独立操作。未修复的只读快照在无活动处理时不直接暂停/取消，返回修复建议而非 JSON 解析 500；运行中的停止请求仍按原 SKU 边界处理。
