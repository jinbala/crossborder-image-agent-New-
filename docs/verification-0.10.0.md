# 0.10.0 本机验收记录

日期：2026-10-20。需求基线：[实施进度](./implementation-progress.md)。本版为双语框架与首批核心页面交付，不是完整双语或全项目上线完成。

## 实现范围

新增持久化中英文界面选择、321 项 UI 英文文案、React 语言上下文及只读 AST 文案审计。覆盖导航、登录/初始化、首页、采集、SKU 图包、客户端恢复、技术支持诊断、状态徽章和通用分页。

语言切换不刷新路由、不以语言作为页面 key；保留输入和任务状态，不翻译用户商品标题、SKU、文件路径/名称、命名模板、后端枚举或协议原文。限制存储时允许本次切换，未知文案保留原文。未调用在线翻译服务。
