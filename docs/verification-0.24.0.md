# 0.24.0 采集明细与停止语义验收

日期：2026-10-21。Windows 0.24.0 / 扩展保持 0.5.4。对应需求第 4.3 节表格搜索/筛选/分页/CSV、任务状态，以及 WEB-TASK-001、COLLECT 断点与失败恢复要求。未通过项不计为完成。

## 实现范围

- 采集商品明细支持 SKU、标题、ID、来源链接和原始错误的字面、不区分大小写搜索，与原状态码筛选组合。默认 25 条，允许 50/100，最大渲染 100 行；筛选变更回第一页，旧页码自动夹取。原 manifest 仍整份读取，不宣称服务端商品分页。
- CSV 导出全部筛选结果而非当前页，UTF-8 BOM/CRLF、双引号转义，字段包括 ID/SKU/标题/销量/原始状态码/图片数/尝试次数/错误码/原错误/来源链接。公式前缀和 Tab/CR/LF 开头单元格加单引号安全前缀；不改原清单，不访问商品站点。
- 取消状态单独展示、保留结果和断点；明确点击并确认才恢复。连续批次防重入，收到手动停止回执即结束，不把仍有 pending 当作续跑许可。
- 后端 run 返回瞬态 stopRequested=pause/cancel，仅在真实控制请求后出现，不写入 manifest。后来的暂停不撤销已有取消；取消后迟到的浏览器回传拒绝 409，不复活任务。用户再次明确 run 仍可恢复未完成项，不重下已完成图片。
- 新增 11 条受控 UI 文案（词典 2,336 条），原标题、错误和状态协议不因切换语言更改。
