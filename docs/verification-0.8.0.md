# 0.8.0 本机验收记录

日期：2026-10-20。需求基线和未关闭项：[实施进度](./implementation-progress.md)。本记录不代替真实平台、模型质量、干净机器或独立安全审计。

## 本次完成

- 使用请求身份上下文及持久所有权，隔离成员的图片任务、批量/工作台任务、原图、结果文件、缓存报告、素材、商品/私有模板、导出和统计。
- 文件下载检查实际路径，符号链接不能借用已授权目录访问未授权文件。新文件只注册到相应资源，未知历史数据不自动归给当前访问者。
- 管理员可预览并批准归属转移，批量包含子任务，旧成员失去该记录访问权，只读接收者仍不能写入。运行中任务不允许分配；共用源文件必须先独立导入，或将相关任务放入同一批量一并分配。没有移动或删除原图。
- 同一用户多个设备继续使用乐观版本冲突；不同成员的相同本地任务 ID 使用不同命名空间，不能读取对方镜像或冲突内容。
- 快照包含资源所有权/文件授权；恢复撤销会话后重新登录，原访问边界仍保持。
- XLSX 回填预览持久化为等待人工任务，刷新/重启后从任务中心继续查看差异、确认生成副本。其他成员即便知道 ID 和审批散列仍被拒绝。
- 工作流旧页面路由懒加载，主入口从约 627KB 降至 296.49KB，消除原单包 500KB 告警。
