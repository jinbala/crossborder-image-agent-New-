## 实现范围

- 业务路由在首次访问时加载，健康检查、静态页面和恢复列表不再预先初始化全部图片生成/处理依赖。认证、成员授权、CSRF、资源归属与本机访问检查仍先执行；同时到达的请求共享导入，但各自保留成员上下文。导入失败交给统一错误处理，下次请求可以重试导入；模块求值本身失败仍可能需要修复并重启服务，不承诺刷新能修复损坏代码。
- 暂停队列的实现仍保留在明确暂停/退出流程，不再因读取恢复列表提前加载全部执行器。没有自动续跑或自动处理图片。
- 第一页历史索引尚未完成且列表为空时，最多五次 100ms 只读刷新，随后恢复 1 秒周期。出现首条任务即恢复普通周期；翻页、成员切换、错误退避、请求取消及索引结束停止轮询的策略保持。
- 专项验证：后端 13/13，前端恢复加载器 11/11。包括共享导入下的成员上下文、守卫先于导入、嵌套路由、错误与路由穿透、重试，以及全新进程健康/恢复请求没有初始化 Sharp/OpenAI。
