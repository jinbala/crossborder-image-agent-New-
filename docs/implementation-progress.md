## 跨端与非功能

- platform.sqlite 持久化账号、商品/模板/对话、版本、设备、同步回执、审计、模拟商店。原图片任务独立 app.sqlite/JSON，统一服务访问。
- 设备一次性 5 分钟码、作用域令牌散列、Windows safeStorage 加密；离线 outbox 原子写/备份、幂等、双版本冲突人工选择、可撤销。
- 同步只传任务摘要，不上传本地绝对路径、图片、下载 URL、Cookie 或密钥。业务原图上传云端不是默认同步范围。
- 当前仍是单组织部署，但成员默认只能访问自己的图片/批量/采集/图包/模板预览任务、商品/素材/自定义模板、文件和同步摘要。系统模板/公告为公共信息；管理员保留全组织访问。后台缓存报告与源文件下载也校验归属，不只过滤列表。
- 旧归属不明数据不自动归给当前访问者：只允许管理员访问；管理员在“个人与团队 → 成员数据归属分配”先看影响、再确认。运行中任务拒绝转移；批量包含子任务；只读接收者仍不能写入。同一源文件若被分配范围外的任务共用，拒绝单独分配，要求独立副本或一并分配，避免误改另一记录的访问权。
- 隔离依赖持久所有权和实际文件路径；快照同步保存 ACL。技术支持为独立第五角色，只能看脱敏环境诊断、本人审计、帮助和公告，不能读业务、账号列表、原图或设备凭据。角色/范围变更仍需独立安全评审，不能因此宣称多团队 SaaS、公开部署或第三方安全认证已完成。
- 停用、角色改变或改密码撤销旧会话、设备令牌及未兑换配对码；恢复旧角色不会复活旧令牌。失去管理员权限或停用时，本地店铺/ERP 授权也失效；这不向真实平台发送远程撤销请求。
- 恢复清单 SQL 分页，不逐个读取所有任务文件。旧工作台清单以每批 16 个后台扫描，校验路径/ID/时间，跳过超过 128MB 的单文件并计入失败，不改源文件；管理员可重建。新状态不会被旧清单覆盖，快照恢复取消恢复前的扫描；非管理员不见全局扫描数量。
- SKU 恢复以完整 SKU 为边界；中断 SKU 可能重做，外部调用不能证明未计费时重新确认，不静默重试收费。
- 快照序列化 SQLite/WAL、素材，可选原图/输出。敏感账号恢复需二次确认；恢复后会话清空，设备/ERP/店铺失效。加密主密钥不放备份，跨机重授权。
- 并发按 CPU、可用内存/磁盘限制，用户可下调；Sharp/ZIP/模型不在 UI 线程。旧工作流页面也改为按路由加载，主入口从约 627KB 降至 296KB，无原 500KB 告警。服务部分同步 JSON/ZIP 仍需大型负载响应压测。
- 本机性能：除原单元夹具外，0.20.0 增加真实 HTTP 的 1,000 行 CSV/XLSX 导入和独立 Electron 冷进程索引 10,000 份历史 manifest；检查 30 秒内首批可见、索引后分页接口低于 2 秒及界面两页 ID 与接口完全一致。耗时见本版验收记录。不含冷 OS 磁盘缓存、真实图片或多人并发，不代替干净机 SLA。
- 中文主流程完整；中英文切换框架和首批核心页面已实现，语言选择持久保存、切换不重置表单、不改业务数据和协议原文。已迁移导航/登录/首页/采集/图包/客户端恢复/支持诊断及状态、分页。全界面双语仍未完成，旧页面/动态标签/服务端提示和原生弹窗继续迁移，详见 [双语进度](./i18n-progress.md)。
