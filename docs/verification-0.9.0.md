# 0.9.0 本机验收记录

日期：2026-10-20。基线与全部未关闭项：[实施进度](./implementation-progress.md)。本记录不代替真实平台、模型质量、干净机器或独立安全审计。

## 本次完成

- 新增独立技术支持角色：只读环境诊断、本人审计、帮助和公告，可确认导出脱敏 JSON。服务端拒绝业务记录、图片、成员清单、设备及修改操作；即便历史上拥有业务记录也不能继续访问。
- 停用、角色变化或修改密码撤销旧会话、设备令牌及未兑换配对码。恢复角色不会复活旧令牌；未知角色从会话和登录入口拒绝。失去管理员权限时本地店铺/ERP 授权失效，不自动请求真实平台。
- 恢复清单改为 SQLite 分页，默认每页 50 条，上限 100，不一次渲染所有历史任务。
- 旧清单按每批 16 个后台索引，校验实际路径、ID、格式和时间；损坏/超大项计入失败，管理员可确认重建，不修改源文件。较旧或同时间清单不能覆盖新索引状态；快照恢复取消旧扫描。普通成员不见全组织扫描数量。
- 10,000 条暂停任务夹具验证首屏低于 2 秒、两页各 50 条且无重复。另验证历史扫描异步返回、坏文件继续、修复后重建和取消旧扫描。此性能证据不含网络、冷磁盘、真实图片、多人并发或干净机器。
