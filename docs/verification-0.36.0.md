## 实现范围

- 历史索引尚未完成时，第一页不足请求页大小的列表继续使用有限快速只读刷新，而不是出现首条任务后立即等待 1 秒。空列表和部分列表共享最多五次 100ms 的预算；满页、其他页和预算耗尽后使用普通周期。扫描完成立即停止，错误仍使用原有有界退避。页大小不是正整数时，非空列表回到普通周期。
- 冷恢复探针记录进程进入、Electron 就绪、会话/扩展准备、本地服务 fork/ready、窗口创建、HttpOnly Cookie 准备及文档完成等时间点，以及同源静态资源、认证和列表请求的时间。仅在隔离 smoke 模式记录，不新增生产 IPC，不输出令牌、Cookie、查询参数或图片内容。
- 整段首屏仍从冷子进程启动前计到可见 50 条任务；增加计时完整性断言，不删减原有断言，不用 API 或文档加载时间替代首屏，也不改变 2 秒目标。30 秒检查仅是既有冷启动稳定性检查。
