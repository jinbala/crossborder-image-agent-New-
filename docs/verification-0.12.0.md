# 0.12.0 本机验收记录

日期：2026-10-20。Windows 0.12.0 / 扩展 0.5.3。基线与未关闭项：[实施进度](./implementation-progress.md)。本版重点为首次回传创建请求的持久恢复，不代表 Temu 实站已验收。

## 本版实现

- 扩展在提交前保存请求标识、商品和选项；响应丢失及后台重启后重发原请求，不采用后来修改的界面规则。收到任务 ID 后压缩保存回执，继续按图断点回传。
- SQLite 以成员与请求散列为唯一键，原子登记任务身份和恢复快照；文件落盘后标记 ready，不自动删除请求键。重复请求返回原任务的当前清单，不覆盖已完成进度。不同内容同键拒绝，所有权转移后旧成员无权回放。
- 进程在登记后或文件落盘后退出，可恢复同一 ID；现有图片或清单损坏时停止，不能用初始快照覆盖已有结果。新建与备份恢复在单服务内互斥；恢复后缺失请求回执且创建世代不一致时停止，不偷偷另建任务。
- 新扩展首次创建要求客户端具有版本化幂等能力；旧服务会显示升级提示并保留清单。已知任务 ID 的继续回传仍沿用已有路径。未确认任务 ID 时，重新采集等入口不会丢弃请求标识。

## 边界与后续

本保证针对新版扩展带请求键的创建路径，普通 Web 表单、表格入口尚未接入请求恢复；手动清除扩展数据或明确重置不在自动恢复保证内。不是分布式事务或无限期完整业务备份承诺。

用户确认“本地会话已失效”出现在 Edge 直接访问客户端地址后；这符合本地会话保护，不是已证明的扩展配对失败。真实回传图片、少量深采、人工验证码恢复仍待用户验收。没有自动关闭旧客户端或修改 Edge 登录态。

原静态 JSX 双语审计仍有 1,195 处（19 个文件）；本版未扩充双语覆盖。模型权重与许可、真实服装图效果、官方模板导入、干净机安装卸载、签名与公网部署仍待条件。无商品发布、线上改价、验证码绕过、模型下载或 Git 推送。
