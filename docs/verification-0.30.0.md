- 只读恢复状态禁止直接续跑、重试、浏览器图片回传和持久化暂停；后端在加锁前及锁内复核，不能借一次业务操作偷偷修复清单。

- 修复与整工作区恢复互斥；活进程持有的旧锁不因超过十分钟而被抢占。未确认死亡的锁也不自动清理。
- 对恢复后可执行的采集参数、商品 ID/索引、图片来源和输出相对路径增加结构校验。身份、结构、路径异常拒绝执行，不悄悄丢弃原进度。不是对所有原文件的完整性扫描。

- 采集重新发布 ZIP 使用原子替换，不先删除旧包。本轮未把采集 ZIP 升级为多版本不可变归档。
