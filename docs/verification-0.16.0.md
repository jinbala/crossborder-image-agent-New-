# 0.16.0 本机验收记录

日期：2026-10-20。Windows 0.16.0 / 扩展 0.5.3。对应需求 4.3 的交互、确认、状态与双语，以及单品图片工作流。完整范围仍按 [需求基线](./xingya-web-client-development-requirements.md) 和 [实施进度](./implementation-progress.md)；不把本地测试当作 Temu、官方店铺或真实模型成功。

## 修复与实现

- useTask 对读取建立当前任务与请求代际边界；切换任务立即隐藏旧任务，旧读取/失败不能覆盖新读取，返回不同任务身份时失败关闭。读取失败清除旧任务并提供重试。平台规则、生成、审核、导出页增加空任务保护；商品页原有重试继续回归。
- 平台目录加载使用独立错误和重试入口，避免与任务读取互相清除错误。任务中不可用的平台保留原 ID 并阻止保存，直到用户明确移除/重新选择，不静默替换成第一个平台。保存期间锁定目标输入。
- 工作流模板页增加加载/刷新、忙碌锁定、保存后选中及结果反馈；前端修改已有模板和删除模板显示名称、影响范围并要求确认，取消不发对应写请求。删除编辑中的模板会退出该编辑状态。系统模板不可直接删改；没有新增旧模板 API 的审批令牌契约。
- 首页、平台规则、模板、导出与步骤导航新增 164 项 UI 文案，词典共 1,541 项；商品/模板名、描述、SKU、目标枚举、规则原文、建议和 ZIP 内容不翻译。规则摘要只翻译自身受控标记。
- 状态徽章补齐 draft/queued/running/waiting_user/paused/partial/cancelled 等，未知状态显示原值，不再误标“新任务”。英文进度卡可换行，较窄容器使用 4 列，避免文字溢出。
