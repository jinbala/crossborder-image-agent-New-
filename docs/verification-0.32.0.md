## 实现范围

- 修复恢复 SQL 仅覆盖批量、采集、SKU、部分图片状态的问题。11 类本地业务任务统一显示 queued/running/waiting_user/paused/failed/partial，已持久化的模板回填、采集计划和本地模拟沙箱现在可从恢复页进入。
- 排除 draft/completed/cancelled、远程设备命令及已有父批量的图片子任务。保留 SQL 分页、成员过滤、只读快照提示，查看不变更归属、清单、模拟写入或审批。
- 非采集/SKU 工作流只是进入已有详情/预览，不冒称新增通用续跑执行器。模板仍检查批准散列与源文件散列；模拟任务仍为本机沙箱，人工批准后才执行，不连接真实店铺。
- 旧辅助清单构建器使用相同的类型/状态规则；状态和五类操作提示接入双语，业务名称不翻译。任务中心新增采集计划、本地模拟沙箱类型筛选。
- 完成一次队列动作不等于业务完成：识别队列 completed、批量 waiting_confirm 时按等待人工确认索引；运行、暂停、取消中的队列控制仍优先。索引策略标记从 2 升到 3，仅自动刷新核心图片/批量索引，不改变数据库表结构、不重新扫描已完成的万条旧清单。
- 中文模板文件名上传回归确认了原来的 multipart Latin-1/UTF-8 解码错误，模板上传统一复用既有文件名解码器，保留业务原名；不改变源工作簿字节。
