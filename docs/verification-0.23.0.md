# 0.23.0 导出与预检报告双语验收

日期：2026-10-21。Windows 0.23.0 / 扩展 0.5.3。对应需求第 4.3 节 P1 中英文、状态/计数及显示一致性，保留需求原基线，不把模拟沙箱当成官方平台成功。

## 实现与范围

- 资料包/CSV、上传预检、Payload、沙箱提交模拟、安全报告，以及扫描候选、来源和 SKU 队列提示的受控标签通过显式 t 参数本地化，不引入全局环境或翻译服务。未知枚举、字段名、路径、SKU、原始建议/错误不送入翻译函数，即使内容碰巧与文案键相同。显示投影不修改输入、导出 JSON、业务状态或请求枚举。
- 新增 71 条文案，词典 2,313 条。目录、报告计数、布尔显示、空态和生成回执可切换；回执插入文件名时保持 $& 和花括号等原文，不把插值再解析。沙箱状态明确为模拟接收，不冒充真实上传。
- 扫描反馈改为结构化状态，渲染时按当前语言生成文案，切换后无需重复扫描；失败样式依据状态而非中文字符串前缀。批次 ID/原始错误通过占位符原样插入。
- 配置、沙箱支持、真实上传支持只认可严格 true，字符串 false/true 不再被当作支持。原始报告仍保留原值；没有因此启用真实上传。
- 检查发现结构化包与 CSV 的 GET 预览缺失 includeRealSamples，界面选中真实样本但预览仍用默认值。两种预览均修复，严格 true 才发 true，与创建请求一致；不授予付费或平台写入权限。CSV 创建确认也使用当前语言。

原始警告/建议、技术字段和尚缺稳定来源标记的服务端系统消息仍不整体翻译。templateAudit、singleImageGeneration、reviewReport、autoFixPlan、finalAcceptance 及原生弹窗等继续开发，不能宣称全系统双语完成。
