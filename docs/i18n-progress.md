## 已实现

- React LocaleProvider + 中文原文键/英文文案表；默认简体中文，可选 en-US。界面语言通过 localStorage 独立键保存，不把账号或业务记录放入语言设置。
- 登录、协议页和主导航均有语言入口；改变 document.lang 和页面标题。切换只更新 React 上下文，不通过 key 重挂载页面，不刷新路由，因此保留表单和任务状态。多窗口接收 storage 事件；浏览器禁止存储时不影响启动和本次切换。
- 已接入：导航、登录/管理员初始化、首页、图片采集、SKU 图包、客户端恢复、支持诊断、任务中心、商品与个人空间、账号公告、素材模板、创作、同步授权、商务预演/模拟沙箱、结果和上传、桌面更新提示、状态徽章与分页。0.11.0 文案表 816 项；动态业务字段不算翻译文案。
- 图片角色/状态等受控标签在显示时翻译，提交给服务端的枚举、命名模板、占位符、图片文件名、商品标题、用户输入和任务数据不翻译。未知文案回退到原文，不调用第三方翻译服务，也不额外上传数据。
- 中文协议原文和同意版本保持不变，协议页明确告知这是中文原文，英文界面不冒充经审定的英文合同。
- 本地/外部处理区别、可能收费确认、验证码人工处理和数据去向等首批页面安全提示同步翻译，不仅翻译标题。

## 开发工具

在 frontend 运行 npm.cmd run i18n:audit 获取只读清单；加 --check 可作为所选页面的静态门禁。工具使用 Babel AST，只处理 JSX 静态文案/显示属性/字面量回退，不碰 value、业务对象、网络参数和事件处理器。语言下拉的双语身份/本族语名称通过 data-i18n-skip 显式保留。

批量机械迁移需显式传入 --apply 和 JSX 文件清单；之后必须人工处理动态标签、确认框、变量插值和词典，不能将机械替换等同于翻译完成。实际覆盖仍以语言切换后的交互验收为准。
