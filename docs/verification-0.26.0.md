# 0.26.0 SKU 结果表与恢复预检验收

日期：2026-10-21。Windows 0.26.0 / 扩展保持 0.5.4。对应需求第 4.3 节表格/确认/状态，SKU-002/009、WEB-TASK-001、IMAGE-003。

## 本轮实现

- SKU 图包页结果表支持 SKU、角色、文件名、错误码/原错误的字面搜索，状态筛选及 25/50/100 行分页；默认只渲染 25 行，最大 100。只列出已有断点的 SKU 汇总，不把缺席的待处理 SKU 虚构成成功。
- CSV 导出全部筛选结果而非当前页，UTF-8 BOM/CRLF/双引号转义和公式样式安全前缀；SKU、原角色代码、原始错误不随界面语言改写，源报告不修改。这是结果汇总，不是平台刊登 CSV。
- 新 GET /api/workbench/sku-packs/:id/resume-preview 只读读取真实恢复计划，准确区分未完成与失败重试范围，给出本次 SKU/图片数、输入散列、当前抠图去向和预检 hash。已经完成的 SKU 不读取或要求其输入缓存仍存在，也不重新制作。
- 恢复按钮先显示真实处理数量；远程抠图还会重新读取实际服务 origin、说明可能费用，再由本次确认决定。取消不提交，不把之前任务保存的费用批准当作本次授权。防重复点击、换结果页后丢弃旧响应和旧确认。
- 远程恢复 API 必须提交 strict confirmPaidMatting=true 和当前预检 hash；页面所有恢复都提交 hash。来源字节、规则、范围、归属/工作空间世代、服务去向变化会拒绝旧确认；拿到执行锁后再次校验，之前不处理图片。旧本地免费恢复 API 仍支持 confirm=true；不赋予外部调用权限。
- 当前范围、逐图散列、目的地址、审批时间保存至 resumeApproval 并进入结果 ZIP，保留原采集来源追踪。当前错误/费用原始状态不因切换语言变化。
- 回归发现按 SKU 再分组和恢复时重复去除目录根，导致 SKU-A/详情/main.png 被拆为错误 SKU。新增回归先失败（2 个分组而非 1），修复为只在最初选择目录时去除一次；已规范化路径在子任务和恢复中保留。原单层目录兼容。
- 新增 11 条受控文案，词典 2,366 条。动态辅助模块、后端系统消息和原生弹窗的完整双语仍不因此关闭。
