# 0.21.0 结构化资料包一致性验收

日期：2026-10-21。Windows 0.21.0 / 扩展 0.5.3。对应需求 4.3 数量与错误说明、6.4 图片格式、7.1 输出包散列、8.1 异常隔离，以及图片处理到刊登资料包的本地衔接。原需求基线不变，不把资料包导出等同于平台上传成功。

## 修复范围

- 结构化资料包的固定 .jpg 文件名不再只是复制源字节：Sharp 实际解码，校正方向、sRGB、透明补白，以质量 95 输出 JPEG。每图记录源 SHA256、输出 SHA256、字节数、格式与尺寸；用户原图不修改。这会重新编码 JPEG，不承诺输出与源图字节相同或无损。
- 丢失、损坏、不合法路径、超过 50MB、超过 40MP、不可读取、多页/不支持格式或写入失败，按图记录 errorCode、missing 和恢复提示，其余图片继续。不支持格式不伪装成功。失败写入会清理本次创建的未完成文件；清理不成则整包失败，不把脏文件当作完整结果。
- 生成后按实际写入结果重新计算数量，根清单、每 SKU 清单、最终目录树和 HTTP 返回一致。包内 CSV 只引用实际存在的图片；使用本次捕获的商品数据，避免压缩期间另一页面编辑商品后，把新字段和旧图片混成同一份资料包。独立 CSV 导出保持原接口语义，不因此被宣称已验证磁盘文件。
- ZIP 返回 SHA256/字节数，界面显示散列；结果卡和目录树优先使用最终结果，不再被旧预览覆盖。更改导出选项会清除旧预览/结果显示，但不删除已导出的文件。忙碌期间导出选项禁用，防止规则与回执错配。
- 按 Windows 大小写不敏感规则检测清理后的目录重名，预览/生成均拒绝有歧义的路径，提示调整 SKU/平台名，不静默覆盖。ZIP 输出流的错误和归档警告被处理为请求失败，不再形成未处理 stream error 或假成功。
- 根清单安全说明明确：不调用 Provider、不上传、不改原任务；创建输出访问授权记录会写入数据库，因此 noDatabaseWrite=false、noTaskMutation=true、createsAssetGrants=true，不能声称完全零数据库写入。
- 补强 Windows 目录名边界：点号目录/路径穿越、设备保留名、末尾点号、超过 200 字符的单段目录写入前拒绝。未知平台名不再通过对象原型属性查找得到函数/对象。
- 验收页离页警告读取实时控制器与当前表单，而不是旧 effect 捕获的状态：已保存/重置后不应继续错误拦截，尚未来得及触发自动保存 effect 的新编辑仍受保护。自动化测试步骤增加阶段进度和超时失败报告；不自动绕过未保存警告，不把超时记成通过。

预览目前基于任务记录估计可导出数量；生成时进行实际解码和写入检查，因此文件在预览后丢失/损坏时最终数量会变化。源图预检、同平台多站点/多语言 target 的完整导出映射仍需后续专项补齐，不能把当前平台/SKU 分组当作这些边界已支持。
