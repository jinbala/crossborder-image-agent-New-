# 0.28.1 Temu 图片回传失败诊断修复

日期：2026-10-23。对应需求 TEMU 图片回传、断点继续及第 4.3 节真实状态。客户端 0.28.1、扩展 0.5.5；不是全部需求完成声明。

用户反馈扩展 0.5.4，旧提示“Failed to fetch”；当前检查时未发现运行中的工作台客户端，但尚未取得用户当前服务地址，不能证明历史错误唯一根因为客户端关闭。真实商品采集已有用户 1 成功/0 失败反馈；真实图片回传仍未验收通过。

## 实现范围

- 图片站请求与本机接收分别记录阶段/代码；可见错误不复制图片签名查询参数、原始网络内部错误或远端登录 HTML。
- 图片请求 25 秒总时限，覆盖响应头及响应体；逐块读取，按实际字节上限 25MB 检查，不信任 Content-Length。空图、HTML、HTTP 拒绝、超大及无效地址均保留失败，不上传。
- 本机断线/超时、配对撤销、服务 5xx 后停止本轮，保留未处理数量；部分失败不再报告全部完成。图片站单图失败继续其他图。
- 重新发送复用同一任务，跳过本机已持久化图片。已有创建回执丢失、MV3 重启、验证码人工处理和权限机制保持；不自动重采、不清空用户清单。
- 任务回执响应体中断/格式无效有独立错误；原请求标识不丢，重新发送找回同一任务。继续读取时核对任务身份与商品列表，不把异常空结果当作零图完成。
- 弹窗显示失败阶段、代码和本轮未处理数量；标题版本与 manifest 一致。已知本地任务并不等于图片传输成功。
