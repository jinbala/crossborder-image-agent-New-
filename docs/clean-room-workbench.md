# Clean-room 运营工作台复刻说明

## 目标

在不复制原应用混淆代码、品牌、私有服务、账号数据或密钥的前提下，复现可验证的跨境图片生产和运营工作流。

## 静态观察到的功能范围

目标应用的已发布制品中可以确认以下功能入口或业务流程：

- 图片采集、下载、抠图和图包整理。
- SKU 图片排序、改名、压缩以及主图、附图、方图、色块图、详情图等分类。
- Temu 素材上传映射和批量刊登模板流程。
- 多平台刊登字段替换、重试、跳过和错误日志。
- 百分比、固定金额、多轮调价以及规则导入导出。
- 浏览器配置、登录、授权、更新和会员状态。

## 当前自主实现

当前版本采用本地优先的独立设计：

| 模块 | 状态 | 当前行为 |
| --- | --- | --- |
| 图包处理 | 可用 | 批量改名、压缩、格式转换、尺寸限制、方图补边、ZIP 和 manifest 导出 |
| SKU 文件夹图包 | 可用 | 整目录上传，按 SKU 分组；支持自然/上传/随机/拖拽顺序、目标 KB 自适应压缩、感知去重、文件名/手工/图像内容辅助角色识别；支持占位符命名、原图保留、预处理、自动方图、ZIP 和 manifest 导出 |
| 采集与批量下载 | 可用 | CSV/XLSX 导入或粘贴公开链接、公开页面标题/销量/图片提取、销量过滤、连续或分批执行、断点恢复、防丢备份、额外等待、失败继续和 ZIP 导出 |
| 刊登预演 | 可用 | 支持 Temu、Amazon、AliExpress、TikTok Shop、Shopee、Shein、Ozon、Mercado Libre 字段预检和草稿 CSV |
| 调价预览 | 可用 | 支持 1–10 轮百分比/固定金额规则、尾数处理、逐步轨迹和 CSV 导出 |
| 素材台账 | 可用 | 持久化 SKU、平台、素材 ID、图片用途、文件名和备注，支持筛选、更新与 CSV 导出 |
| XLSX 模板识别 | 可用 | 仅读取工作簿表头与少量样本行，建议字段映射并报告必填缺口；拒绝 VBA 宏 |
| 主体抠图 | 可用 | SKU 图包可批量使用 Sharp、rembg 本地 ONNX AI、外部高清抠图或 Image2；rembg 推理不上传图片，模型需单独安装并核对权重许可；可能收费的 provider 必须逐任务明确确认 |
| Temu 深度采集助手 | 可用，待实站验收 | v0.4.0 支持手动当前页及单标签低频自动采集，合并 DOM、懒加载、背景图、结构化 JSON、脚本和变种图片；手动模式可将登录态图片字节回传本机；出现验证码时暂停，不绕过验证 |
| 店铺自动发布 | 未接入 | 不登录店铺，不上传商品，不绕过验证码或访问控制 |
| 线上自动改价 | 未接入 | 只计算本地预览，不修改线上价格 |

刊登 CSV 是字段预检草稿，不宣称是任一平台当前版本的官方导入模板。接入官方模板前必须用用户提供的最新模板进行字段映射和样本验证。

## 后续顺序

1. Temu 实站验收：由用户在自己的已登录浏览器中加载扩展，选取少量商品验证页面结构、销量字段和验证码暂停行为。
2. 模板回填：基于已经识别的表头，把刊登预演数据与素材台账安全填入用户提供的工作簿副本，同时保留原模板结构。
3. 授权平台适配器：只有在用户明确授权、平台允许且完成沙箱验证后，才实现真实写入。
