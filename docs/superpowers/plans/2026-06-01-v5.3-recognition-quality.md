> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Architecture:** Backend adds a pure analysis service and attaches its report to task responses in memory. Frontend adds display helpers and a new ProductInfoPage section. Tests are written first and verified red before implementation.
