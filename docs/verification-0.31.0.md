## 本轮变化

- 历史扫描遇到主清单缺失或 JSON 截断时，使用既有 SKU/通用快照读取器，按同一选择规则只读读取当前备份或已发布 ZIP。支持采集、SKU、普通图包、采集计划、场景、刊登预演、调价预览和模板回填。
- 索引保存快照来源标记，客户端恢复列表显示只读提示和管理员可见的恢复计数。查看详情后仍需原来的明确修复确认，不自动续跑。
- 后台扫描在系统读取上下文运行，但不创建/变更归属。列表仍按当前成员过滤；非管理员看不到全局恢复计数。新的较旧快照不能覆盖已索引的较新状态。
- 主清单身份不匹配、非法路径、体积超限、损坏的最新发布 ZIP 仍拒绝，不以其他任务或旧版本替代。工作区根目录越界拒绝；目录枚举权限错误不再误报为空扫描完成。
- 扫描不修改清单、备份、ZIP、图片，不调用图片下载、Provider 或平台接口。不是普通任务显式修复功能，也不是重新扫描后自动删除历史索引的策略。
